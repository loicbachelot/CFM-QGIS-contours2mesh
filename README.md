# QGIS contours2mesh plugin

This is a QGIS plugin used to create the triangular mesh representing the fault surface from the contours. It is one of 3 QGIS plugins used to make 3D fault geometries.

Installation and use instructions are available here: https://cascadiaquakes.github.io/fault-geometry-building-tutorial/QGIS_plugin.html
